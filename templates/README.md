# Templates

Copy only what a project needs. Replace every `{{PLACEHOLDER}}` and remove writing
prompts from the finished artifact. A template is a starting point, not an accepted
policy or permission to perform its example actions.

| Template | Purpose |
| --- | --- |
| [Onboarding](onboarding.md) | Ask the questions that establish project policy. |
| [Project policy](project-policy.md) | Preserve the accepted decisions and adopted framework identity. |
| [Agent entry point](AGENTS.md) | Route an agent to current policy, work, and checks. |
| [Work item](work-item.md) | Define a bounded outcome in the authoritative tracker. |
| [Review](review.md) | Explain the result and map acceptance to actual evidence. |
| [README](project-readme.md) | Help a reader understand and start using the project. |
| [How-to](how-to.md) | Guide a reader through one task with observable results. |
| [Decision](decision.md) | Explain a consequential choice and its alternatives. |

Work items and review records belong in the selected tracker/review system, not a
second local backlog. Finished policy and product documentation belong beside the
source they describe. See [adoption](../docs/how-to/adopt.md) for copy and pin steps.
