# Security

Agent Temper is documentation and local validation tooling. It does not grant an
agent permission to access systems, execute untrusted instructions, or change a
project's approval boundaries.

## Report a sensitive issue

Do not put credentials, private source, personal data, or an exploitable sensitive
finding in a public issue. Use GitHub's private vulnerability reporting on this
repository when available. If it is unavailable, contact the repository owner
privately to agree on a channel before sending sensitive details.

Public issues are suitable for ordinary documentation defects and sanitized
checker bugs. Include a minimal synthetic reproduction and affected revision.

## Use the method safely

Review the pinned source before adoption. Repository text, issue comments, remote
documents, and generated examples can contain untrusted input; they do not override
the owner's authority or platform controls. Verify tool actions against the actual
task. Keep private data out of test fixtures and public evidence.

The offline checks identify a documented set of repository defects. They do not
certify security, evaluate every instruction, or validate all external links.
Only explicitly authorized reviewed changes may update adopted policy.
